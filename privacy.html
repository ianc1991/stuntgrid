Privacy

Last updated October 5, 2026

StuntGrid is a racing game. You can play it entirely offline. If you use the online leaderboards, the game sends a few things to the StuntGrid server, described here. Nothing else is collected, and nothing is sold or shared for advertising.

What the leaderboards store

  • The name you choose (3 to 16 characters). It's shown on the leaderboards. Don't use your real name if you'd rather not.
  • Your laps: when you set a best time on a built-in track, the game uploads the lap's ghost file: the track, the time, and the steering, throttle and brake inputs that drove it. The server re-drives the lap to check it. Verified laps are public: anyone can see the time and download the ghost to race against or watch.
  • A secret player key that the game keeps on your device, so the server knows which laps are yours. The server stores only a scrambled (hashed) form of it.
  • Your network address is seen when you connect, as with any website. It's used only to stop abuse (limiting how many players and laps one address can create in an hour) and isn't stored with your laps.

Turning it off

Uploading best laps can be switched off in the game's leaderboard panel; the game then only downloads boards and ghosts. Without ever joining a leaderboard, the game sends nothing.

Deleting your data

To have your player name and laps removed, open a request at github.com/ianc1991/stuntgrid/issues with your player name (or ask in the community channels listed on stuntgrid.com once they're open).

Hosting

This website is hosted on GitHub Pages and the game downloads on GitHub; GitHub may log visits as described in its own privacy statement. The leaderboard server runs on Railway.

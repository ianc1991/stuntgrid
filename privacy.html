Privacy

Last updated October 7, 2026 (accounts added)

StuntGrid is a racing game. You can play it entirely offline. If you use the online leaderboards, the game sends a few things to the StuntGrid server, described here. Nothing else is collected, and nothing is sold or shared for advertising.

What the leaderboards store

  • Your email address, if you sign in (you need to, to put laps on the leaderboards). It's used only to email you sign-in codes: no newsletters, never shown to anyone, never shared or sold. A code is stored only in scrambled form and stops working after 10 minutes.
  • The name you choose (3 to 16 characters). It's shown on the leaderboards. Don't use your real name if you'd rather not.
  • Your laps: when you set a best time on a built-in track, the game uploads the lap's ghost file: the track, the time, and the steering, throttle and brake inputs that drove it. The server re-drives the lap to check it. Verified laps are public: anyone can see the time and download the ghost to race against or watch.
  • A secret key for each device you sign in on, kept by the game, so the server knows which laps are yours. The server stores only a scrambled (hashed) form of it. Signing out deletes that device's key.
  • Your network address is seen when you connect, as with any website. It's used only to stop abuse (limiting how many players, sign-in codes and laps one address can ask for in an hour) and isn't stored with your laps.

Turning it off

Uploading best laps can be switched off in the game's leaderboard panel; the game then only downloads boards and ghosts. Without ever joining a leaderboard or sending feedback, the game sends nothing about you: it only asks GitHub, when the main menu opens, whether a newer build is out.

Deleting your data

In the game, Settings → Account → Delete my account removes your email, name, device keys and laps from the server straight away. Without the game, ask in the StuntGrid Discord or open a request at github.com/ianc1991/stuntgrid/issues with your player name and email.

Feedback

If you use Send feedback in the game, your text, the game's version, your device type (system, model, graphics chip), and, if you tick them, the game's log and your best lap on that track are sent to the StuntGrid team's private Discord channel, along with your player name if you've joined the leaderboards. It's used only to fix and improve the game.

Hosting

This website is hosted on GitHub Pages and the game downloads on GitHub; GitHub may log visits as described in its own privacy statement. The leaderboard server runs on Railway. Sign-in emails are sent through Resend, which handles your email address only to deliver them.
